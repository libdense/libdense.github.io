# libdense.github.io

The website for libdense: https://libdense.github.io

A high-density multiplayer state engine for all-to-all observer simulations
and multiplayer digital twins.

- **Viewer**: an interactive map of the libdense architecture and data flow
  for the current release, with live metrics.
- **Docs**: the libdense documentation, read from
  [libdense/libdense](https://github.com/libdense/libdense/tree/main/docs).
- **Support**: help on [Discord](https://discord.gg/rhEp4vKFVr); commercial
  inquiries, support, licensing and contact at
  [yggengine.com/commercial](https://yggengine.com/commercial).

Source and releases: https://github.com/libdense/libdense

The book: [Dense-Region MMO Server Architecture](https://www.amazon.com/dp/B0H86L5Y1B)
